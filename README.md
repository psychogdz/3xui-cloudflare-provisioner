## 🎯 چرا این پروژه ساخته شد؟

در نسخه‌ها و اسکریپت‌های سنتی، کانفیگ‌ها بر روی پورت‌های متفرقه (مانند `2083`، `2084` یا `2085`) و به‌صورت مستقیم به IP سرور متصل می‌شدند. اخیراً سیستم فیلترینگ و نظارت بر شبکه ایران (DPI / TIC):
1. پکت‌های بازگشتی سرورهای خارجی ناشناس بر روی پورت‌های غیر از ۴۴۳ را با اختلال و قطع ارتباط (Drop / Reset) مواجه می‌کند.
2. پروتکل‌های فاقد رمزنگاری یا هندشیک‌های شناسایی‌شده مانند شادوساکس و ریالیتی‌های بدون فرگمنت را مسدود می‌سازد.

این پروژه برای حل ریشه‌ای این مشکل طراحی شده است:
* **ترافیک از بستر پرسرعت CDN کلودفلر** عبور می‌کند؛ بنابراین اپراتورهای ایرانی تنها یک اتصال مجاز و امن HTTPS به کلودفلر می‌بینند.
* **گواهی SSL معتبر و رسمی Let's Encrypt ECC** با احراز هویت خودکار DNS-01 صادر شده و روی سرور نصب می‌شود.
* **کانفیگ‌های VLESS WebSocket و gRPC روی پورت استاندارد ۴۴۳ و ۸۴۴۳** پیکربندی می‌شوند تا تحت هر شرایطی بالاترین پایداری و پینگ Real Delay واقعی را فراهم کنند.

## ✨ ویژگی‌های کلیدی

- 🚀 **نصب ۱۰۰٪ خودکار با یک دستور:** تمام مراحل بدون نیاز به ورود دستی به پنل انجام می‌شود.
- ☁️ **یکپارچگی خودکار با کلودفلر:** ساخت خودکار رکورد DNS پروکسی‌شده (ابر نارنجی ☁️) و تنظیم Zone ID از طریق API.
- 🔒 **گواهی رسمی Let's Encrypt:** نصب خودکار `acme.sh` و صدور گواهی رمزنگاری امن ECC بدون نیاز به باز بودن پورت ۸۰ یا مداخله دستی.
- 🛡️ **مقاوم در برابر DPI ایران:** پیکربندی پروتکل VLESS + WebSocket + TLS روی پورت ۴۴۳ که آزمون‌های واقعی تاخیر TCP (Real Delay HTTP 204) را با موفقیت پشت سر گذاشته است.
- ⚡ **پشتیبانی از gRPC:** اینباند ثانویه روی پورت ۸۴۴۳ برای اتصال فوق‌العاده سریع با کمترین تاخیر (مناسب تماس صوتی و وب‌گردی روان).
- 🔀 **تولید هم‌زمان لینک دامین و Clean IP:** تولید کانفیگ آماده با آی‌پی‌های تمیز Anycast کلودفلر جهت مقابله با اختلالات احتمالی DNS اپراتورها.
- 🎲 **امنیت بالا با مقادیر تصادفی:** تولید خودکار نام کاربری، رمز عبور قوی ۲۴ کاراکتری، مسیر پنل تصادفی (`/xui_xxxx/`) و شناسه سابسکریپشن منحصربه‌فرد.
- 🚀 **فعال‌سازی خودکار TCP BBR:** بهینه‌سازی سرعت هسته لینوکس و کنترل ازدحام برای افزایش پهنای باند و کاهش پکت‌لاس.
- 📊 **داشبورد نهایی در ترمینال:** نمایش لینک ورود به پنل، رمزها، لینک‌های مستقیم VLESS و سابسکریپشن در قالب یک جدول تمیز به همراه ذخیره در `/root/provisioner-info.txt`.

## ⚡ روش نصب سریع با یک دستور

### روش ۱: حالت تعاملی (Interactive - پیشنهادی)
ترمینال سرور (SSH) را باز کرده و دستور زیر را اجرا کنید. اسکریپت دامنه و توکن کلودفلر را به صورت تعاملی و زیبا از شما می‌پرسد:

```bash
curl -sSL https://raw.githubusercontent.com/psychogdz/3xui-cloudflare-provisioner/main/install.sh | sudo bash
```

---

### روش ۲: حالت کاملاً خودکار با پارامترها (Non-Interactive)
اگر می‌خواهید بدون هیچ پرسش و پاسخی همه‌چیز در یک مرحله اجرا شود:

```bash
curl -sSL https://raw.githubusercontent.com/psychogdz/3xui-cloudflare-provisioner/main/install.sh | sudo bash -s -- \
  --domain "example.com" \
  --cf-token "your_cloudflare_api_token" \
  --subdomain "vpn" \
  --yes
```

## 🔑 راهنمای دریافت توکن کلودفلر

برای اتصال خودکار به کلودفلر نیاز به یک API Token ساده با دسترسی ویرایش DNS دارید:

1. وارد داشبورد کلودفلر به آدرس [dash.cloudflare.com/profile/api-tokens](https://dash.cloudflare.com/profile/api-tokens) شوید.
2. روی **Create Token** کلیک کنید.
3. در پایین صفحه، جلوی **Custom token** روی **Get started** کلیک کنید:
   * **Token name:** یک نام دلخواه بگذارید (مثلاً `vpn-auto`).
   * در بخش **Permissions** دو دسترسی زیر را اضافه کنید:
     - `Zone` — `DNS` — `Edit`
     - `Zone` — `Zone` — `Read`
   * در بخش **Zone Resources**:
     - `Include` — `Specific zone` — دامنه خود را انتخاب کنید.
4. روی **Continue to summary** و سپس **Create Token** کلیک کرده و توکن تولیدشده را کپی کنید.

## 🛠 گزینه‌ها و سوئیچ‌های خط فرمان

| پارامتر | توضیح | مقدار پیش‌فرض |
| :--- | :--- | :--- |
| `-d, --domain` | دامنه ثبت‌شده در کلودفلر | تعاملی |
| `-t, --cf-token` | توکن دسترسی Cloudflare API | تعاملی |
| `-s, --subdomain` | پیشوند ساب‌دامین (مثلاً `vpn` -> `vpn.domain.com`) | تصادفی (`node-xxxx`) |
| `-p, --panel-port` | پورت وب پنل ۳X-UI | `2053` |
| `-u, --username` | نام کاربری پنل مدیریت | تصادفی (`admin_xxxx`) |
| `-P, --password` | رمز عبور پنل مدیریت | تصادفی (۲۴ کاراکتر امن) |
| `--bbr` | فعال‌سازی بهینه‌ساز TCP BBR | `true` |
| `-y, --yes` | اجرای بدون تایید دستی (Non-Interactive) | `false` |
| `-c, --config` | مسیر بارگذاری فایل تنظیمات | `./config.env` |

## 🌐 معماری پروتکل‌ها و دور زدن DPI

پس از اتمام نصب، اینباند‌های زیر در هسته Xray فعال می‌شوند:

```
[کلاینت در ایران]
       │
       ▼ (پورت 443 با TLS معتبر و دامین رسمی)
[شبکه CDN Anycast کلودفلر]
       │
       ▼ (تونل رمزنگاری‌شده با سرتیفیکیت Let's Encrypt)
[سرور خارج شما: 3X-UI / Xray]
       │
       ▼
 [اینترنت آزاد و پرسرعت]
```

1. **VLESS WebSocket TLS (Port 443):** اینباند اصلی CDN. روی همه اپراتورها (همراه اول، ایرانسل، رایتل، مخابرات، شاتل و ...) با پینگ Real Delay کار می‌کند.
2. **VLESS gRPC TLS (Port 8443):** اینباند کم‌تاخیر با قابلیت استریم مالتی‌پلکس برای بازی و مصارف حساس به لیتنسی.
3. **VLESS Reality Vision (Port 2053):** اتصال مستقیم بدون کلودفلر برای شرایطی که مایل به اتصال P2P هستید.

## 📱 نحوه اتصال در کلاینت‌ها

پس از پایان نصب، در ترمینال خروجی زیر نمایش داده می‌شود:
* **لینک سابسکریپشن (Subscription URL):** این لینک را کپی کرده و در بخش سابسکریپشن کلاینت وارد کنید تا تمام کانفیگ‌ها به طور خودکار دریافت شوند.
* **لینک‌های مستقیم VLESS:**
  - **کانفیگ بر پایه دامین:** برای اتصال عادی و خودکار.
  - **کانفیگ Clean IP (آی‌پی تمیز کلودفلر):** اتصال با کمترین تاخیر و عبور تضمینی از اختلالات DNS.

نرم‌افزارهای پیشنهادی:
* **ویندوز:** Happ, v2rayN, Nekoray
* **اندروید:** Happ, v2rayNG, Sing-box
* **آیفون (iOS):** Happ, Streisand, Shadowrocket, FoXray, V2Box
